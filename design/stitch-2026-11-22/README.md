# Stitch tasarım kaynağı

Kaynak proje: [Anasayfa ve Navbar Yenileme](https://stitch.google.com/projects/1388326602978643860)

Bu klasörde Stitch'ten indirilen masaüstü ekran görüntüleri ve `DESIGN.md` renk/tipografi sistemi saklanır. Ekranlar: `ana-sayfa.png`, `ogren.png`, `uygula.png`, `incele.png`, `degerlendir.png`.

Uygulama karşılığı `dist/index.html`, `dist/stitch-theme.css`, `dist/portal.js` ve `dist/media/stitch-shield.svg` dosyalarındadır. Stitch çıktısındaki örnek skorlar, sertifika/rozet iddiaları, canlı güvenlik taraması görünümü ve sahte kullanıcı hesabı siteye aktarılmadı. Mevcut çalışan modüllerin davranışı ve açıklamaları korundu. Mobil tasarımın üst çubuk, alt gezinme ve tek sütun ilkeleri CSS ile uygulandı.

GitHub deposundaki tasarım kaynakları, canlı sitede kullanılan `dist/` çıktısından ayrıdır.
