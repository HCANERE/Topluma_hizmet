Bu dosya yalnızca ekip bilgisayarında açılır. Hesap veya yönetici yetkisi sağlamaz. Girdiler kaydedilmez; oluşturduğun JSON dosyasını depoya eklemeden önce ekipçe gözden geçir.

Üç davranış seçeneği

Hazırlanan senaryolar

    Siteye ekleme

    1. JSON dosyasını indir.
    2. Depo klasöründe node scripts/add-scenarios.mjs DOSYA.json çalıştır.
    3. npm test ile içerik kontrolünü yap; sonra kodu gözden geçir.

    Gerçek kişi, kurum, telefon ve alan adı kullanma. Örnek adreslerde yalnızca example.com kullan.
